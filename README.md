# 🎨 Estudos e Exercícios de Desenvolvimento Web (HTML5 & CSS3)

Repositório dedicado ao aprendizado de front-end, focando na criação de interfaces modernas, estruturação semântica, estilização e recriação de layouts reais (engenharia reversa).

---

## 🔐 Projeto em Destaque: Clone da Tela de Login da Netflix (Primeiro Projeto Web! )

- Primeiro projeto prático desenvolvido na transição para o front-end
- Estruturação semântica básica com formulários, inputs e botões
- Layout responsivo alinhado e centralizado com **Flexbox**
- Imagem de fundo com overlay escuro utilizando `linear-gradient` para legibilidade
- Efeitos interativos com estados `:hover` em botões e links

# 🎨 Estudos e Exercícios de Desenvolvimento Web (HTML5 & CSS3)

Repositório dedicado ao aprendizado de front-end, focando na criação de interfaces modernas, estruturação semântica, estilização e recriação de layouts reais (engenharia reversa).

---

## 📚 Projetos Incluídos

| Projeto | Pasta | Tecnologias | Conceitos Aplicados | Descrição |
| :--- | :--- | :--- | :--- | :--- |
| 🎬 **Netflix Login** | `netflix-clone/` | HTML5, CSS3 | Flexbox, Inputs, Background Overlay | Recriação da tela de autenticação da Netflix para fixar a base de formulários e estilização. |
| 🎵 **Spotify Login** | `spotify-clone/` | HTML5, CSS3 | Flexbox, Custom Checkbox, Social Buttons | Recriação da página de login do Spotify com botões sociais e formulário estilizado. |

---

## 🛠️ Tecnologias e Ferramentas

* **Linguagens:** HTML5, CSS3
* **Conceitos de Layout:** Flexbox (`display: flex`, `justify-content`, `align-items`, `gap`)
* **Ambiente de Desenvolvimento:** VS Code
* **Controle de Versão:** Git & GitHub

## ▶️ Como Executar

Para visualizar qualquer um dos projetos no seu navegador:

1. Clone ou baixe este repositório.
2. Navegue até a pasta do projeto desejado (`netflix-clone/` ou `spotify-clone/`).
3. Dê um duplo clique no arquivo `.html` da pasta para abrir direto no seu navegador.
